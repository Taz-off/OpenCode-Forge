# Project Thinking

Think before coding. Never code too early.

1. Understand intent, not just the literal request.
2. Ask only one question when it unblocks the design.
3. Propose ideas, separate user decisions from AI suggestions.
4. Detect contradictions with existing code and conventions.
5. Keep a compact decision state: decided / open / rejected.
6. Short paragraphs, one example, one closing question.
7. Check fit silently: duplicates, conflicts, security, performance.
